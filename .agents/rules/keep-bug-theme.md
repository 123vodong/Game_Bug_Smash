# Keep the Bug Theme

Bug Smash is about smashing bugs. Reworks (art, renderer, UI, Three.js migration) must never lose the core programmer theme:

- **Bugs:** the whole bestiary (Null, Memory Leak, Race Condition, Legacy, Heisenbug, ladybug, critical/dead bug...) with recognisable looks and behaviors.
- **Dev props:** code-snippet obstacles, laptop as weapon, monitors, mugs, rubber duck, keycards, servers, terminals.
- **Cast:** PM, Boss, Tech Lead, THE DEADLINE; office humor in names, feed lines, loading tips, chat and skill/item names.
- **Rule:** if a model/asset is missing, use a placeholder that still reads as the bug/dev thing, never a generic one.
- **Checklist before finishing a rework:** list these theme elements and confirm each is still present and visible in the new version.
- **Do not change** camera perspective or art style when asked only to "make it prettier"; ask first.
