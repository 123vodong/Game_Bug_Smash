# Stickyman Skill System – MOBA Proposal

## Controls
- PC: WASD / Arrow keys to move
- Space: Basic attack (Laptop Smash)
- Mouse: Target selection / auto attack
- QWER: Skills

## Skills

### Q — Bug Dash
Cooldown: 8s
Dash forward and damage enemies.

### W — Laptop Shield
Cooldown: 12s
Block next hit and reduce damage.

### E — Debug Roll
Cooldown: 10s
Quick movement + brief invulnerability.

### R — Deadline Break (Ultimate)
Cooldown: 60s
Area smash that knocks enemies back and stuns.

## Notes
- Basic attack has no cooldown.
- Skills designed for mobile and PC.
- Supports offensive and defensive playstyles.
