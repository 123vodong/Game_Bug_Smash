
# Multiplayer 3D Expansion Proposal – *Hate the World*

## 1. Overview

This proposal describes a major evolution of **Hate the World** into a **3D multiplayer game** with a large open map, dynamic enemies (bugs), and competitive/cooperative play modes.  
The core fantasy remains the same: **stickman developers using laptops to smash bugs**, but scaled up to be chaotic, social, and replayable.

The goal is to:
- Reduce boredom through **player-driven chaos**
- Increase replayability via **multiplayer competition**
- Future-proof the game by refactoring it into **3D + scalable maps**

---

## 2. Core Multiplayer Modes

### 2.1 Mode A – Solo Infinite Loop (Competitive)

**Description**
- Each player plays **alone** in an infinite, procedurally looping map.
- Bugs continuously spawn, hide, and roam the map.
- Difficulty ramps up over time.

**Key Mechanics**
- Infinite bug waves
- Random bug behaviors
- Score based on:
  - Bugs smashed
  - Combos
  - Survival time

**Ranking**
- Global leaderboard
- Daily / weekly seasons
- Ghost replays of top players (optional)

---

### 2.2 Mode B – Team Battle Rooms (Competitive / Co-op)

**Description**
- Players form **teams** (2–4 players per team).
- Teams join a **room** and must clear **all levels/maps**.
- The winning team is the one that smashes the most bugs or defeats the final boss first.

**Flow**
1. Create / Join Room  
2. Team Assignment  
3. Multi-map run  
4. Final Boss Arena  
5. Results + MVP screen  

---

## 3. Player Characters (3D)

### Stickman Developer
- 3D stickman body
- Laptop as main weapon
- Debug-themed cosmetics

**Abilities**
- Smash bugs
- Jump / dash / wall climb
- PvP knockback attacks

---

## 4. Energy & Laptop Breakdown System

- Every player has an **Energy Bar**
- Attacks consume energy

**Laptop Broken State**
- Triggered at 0 energy
- Player enters *Fixing Laptop* mode
- Temporary disable attacks
- Auto or assisted recovery

---

## 5. Bugs (Enemies)

**Types**
- Flying bugs
- Armored bugs (bounce away)
- Stealth bugs (teleport)
- Swarm bugs
- Boss bugs

**Key Behavior**
- Bugs roam, hide, and escape dynamically

---

## 6. PvP Interactions

- Players can attack each other
- Energy drain on hit
- Optional per game mode
