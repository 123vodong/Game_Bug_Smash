# Optional Character Atlas Input

The runtime can auto-detect `devstick.png` and `devstick.json` here; without them it uses the
existing fallback poses in `../stickman/`.

No atlas in this folder is currently approved as production art, and no Mixamo/Blender pipeline
has been selected. Add files only after their source, license, visual approval, and in-game fit are
recorded. See [`ART_QUALITY_PASS.md`](../../../.claude/context/tasks/ART_QUALITY_PASS.md).
